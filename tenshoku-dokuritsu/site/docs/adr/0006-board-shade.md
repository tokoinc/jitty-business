# Board の `--c-shade` は hair と同じ値にする

## 状況

Board の記事面は、右下へずらした二重輪郭で「差し替えられる板」に見せる（2.7 S1）。外側の線は輪郭なので `--c-line` を使う。その内側、本体と外側の線のあいだの面の色が `--c-shade` である。2.12 の初期値の表にはこのトークンが無い。見本のフラットは `#d5dae2` を使っている。手順は、`line` か `hair` をもとに決め、ADR に書くことだけを求めている。

## 選択肢

1. `--c-shade` を `--c-line` と同じにする（light `#18202C`、dark `#C3CBD8`）。
2. `--c-shade` を `--c-hair` と同じにする（light `#CDD3DB`、dark `#2C3646`）。

## 決定

選択肢2。`--c-shade` は `light-dark(#CDD3DB, #2C3646)`。外側の線は `--c-line` のままにする。

## 理由

ずらした面は装飾の塗りである。`line` を面に塗ると、光の面がほぼ墨色になり、輪郭との差が消える。`hair` の light `#CDD3DB` は見本の `#d5dae2` に近い。`hair` は装飾の細線に使い、操作部品の境界には `line` を使う（2.12）。この面の境界は、`--c-line` の外側の線が担う。
