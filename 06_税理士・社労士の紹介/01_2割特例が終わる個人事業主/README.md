## ジャンルの前提

「税理士の探し方」の一般論より、制度の節目で専門家が要る人に絞ります。

[TOP20.md](../../../../TOP20.md) での評価です。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 税理士・社労士の紹介 |
| 順位・点 | B2B 6位・79.5点（単価3.5・成果の軽さ4・需要5・参入しやすさ3・安全性4） |
| 単価・成果地点 | 推定 1万円前後／紹介申込・問い合わせ |
| いま稼ぎやすい理由 | インボイスの2割特例は9月末を含む課税期間で終了し、個人事業者は2027・28年に3割特例へ。年末調整の改正、2〜3月の確定申告が続く |
| 注意点 | 紹介サイト経由の案件が中心。単価と承認条件を比べて選ぶ |

単価の「実例」は元レポートの新着案件、「推定」は公開データがなく見立てた値です。
