## ジャンルの前提

「採れない業種」に絞り、求人媒体・スキマバイト・採用代行の使い分けを示す記事にします。

[TOP20.md](../../../../TOP20.md) での評価です。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 採用支援（求人広告・ダイレクトリクルーティング・採用代行） |
| 順位・点 | B2B 5位・79.5点（単価3.5・成果の軽さ4・需要5・参入しやすさ3・安全性4） |
| 単価・成果地点 | 推定 1万円前後／資料請求・問い合わせ |
| いま稼ぎやすい理由 | 7月の人手不足倒産は過去最多の63件。求人倍率は例年12月にピーク |
| 注意点 | 効果は約束できない。業種特化（介護・建設・飲食など）で差別化 |

単価の「実例」は元レポートの新着案件、「推定」は公開データがなく見立てた値です。
