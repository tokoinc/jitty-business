## ジャンルの前提

中小には「取引先に求められた」「補助で安く始められる」の2つが刺さります。

TOP20.md での評価です。

| 項目 | 内容 |
| --- | --- |
| ジャンル | サイバーセキュリティ（UTM・EDR・脆弱性診断・バックアップ） |
| 順位・点 | B2B 7位・78.5点（単価3・成果の軽さ4・需要5・参入しやすさ2.5・安全性5） |
| 単価・成果地点 | 推定 数千〜1万円／資料請求・問い合わせ |
| いま稼ぎやすい理由 | 上半期のランサムウェア被害は過去最多の123件で、64%が中小企業。取引先に対策水準を示す評価制度（★3・★4）が2026年度下期から始まる予定 |
| 注意点 | アフィリエイト案件はまだ少なく、専門的な解説が必要 |
