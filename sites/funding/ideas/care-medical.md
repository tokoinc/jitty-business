# 介護・医療の事業者（資金調達）

ニッチ.md（2026年10月版）のB2B 2位「資金調達」の切り口です。

| 項目 | 内容 |
| --- | --- |
| 狙う読者 | 訪問介護などの経営者 |
| 検索の例 | 「介護報酬 ファクタリング」 |
| 勝てる理由（根拠） | 訪問介護の倒産は2025年1〜11月で85件、3年連続の過去最多。87%が従業員10人未満 |
| 合う案件・媒体 | 介護報酬・診療報酬ファクタリング（ASPで要確認） |

## ジャンルの前提

「ファクタリングとは」は飽和しているので、業種と資金が詰まる理由ごとに分けます。

手数料の高い業者と混同されないよう、手数料の目安と運営会社を明示する広告主を選びます。

TOP20.md での評価です。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 資金調達（ファクタリング・ビジネスローン・請求書カード払い） |
| 順位・点 | B2B 2位・83.0点（単価4・成果の軽さ5・需要5・参入しやすさ3・安全性3） |
| 単価・成果地点 | 実例 7,300〜16,100円（法人10,549円／個人5,327円）／問い合わせ・申込 |
| いま稼ぎやすい理由 | 2026年度上半期の倒産は5,373件で5年連続増。人手不足・物価高倒産は過去最多、税金滞納による倒産は前年の2倍 |
| 注意点 | 手数料と運営実態を確認できる事業者に絞る |

単価の「実例」は元レポートの新着案件、「推定」は公開データがなく見立てた値です。
