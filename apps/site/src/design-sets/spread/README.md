# Spread — 曲面と見開き

原形は、大きな曲面で切った見開き。左の補助面と主面を円弧で分け、右端の細い背に縦の章標題を置く。

`main.sp-faces` が主面（`.sp-face`）と次の見開き（`.sp-nextface`）を包む。円弧で分かれて見えるのは CSS の仕事（ADR-0007）。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。

| トークン | 値 |
| --- | --- |
| `--g-line` | 1px |
| `--g-arc-x` | 360px |
| `--g-arc-y` | 300px |
| `--g-spine` | 4.75rem |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 円弧で切った主面と、右端の背。次の見開きは左上の円弧で開く |
| S2 | 円形スタンプ。棚名は水平の文字で円の中央。記事面では小さな円（棚の番号）と棚名 |
| S3 | 大きな章番号と明朝の見出し。広い画面では背に縦書きの短い章ラベル |
| S4 | 解説・実務は文字の見開き（大きな番号＋題。実務は丸の目盛り）。比較は右上が円弧の表の扉。ニュースは大きな日付と1行の題。論考・人物は曲面の画像枠と、張り出す題名面 |
| S5 | 問いの円、上辺が円弧の検索欄、丸い目的の選択肢。条件群は結果の右で、円弧に沿って段をずらす |
| S6 | 条件・根拠は欄外の細い背と、本文へ向かう点線。論点帯は右上が円弧の票。狭い画面では横書きの短いラベル |
| S7 | 角の一つが円弧の吹き出し（`.sp-pop` だけ） |
| S8 | 背の現在のラベルが太くなり、主面へ半円を出す。補助面では選んでいる棚の円が塗られる |
| S9 | 主面の右下で円弧が閉じ、次の見開きへ続く。部品自体は小さな印 |

## 形の予約

| 形 | 使ってよい部品 |
| --- | --- |
| 背の縦ラベル | 目次、条件、根拠、選択中、読みかけ、連載 |

背そのものに載る棚の説明・関連用語・最近確認した記事も、同じ柱の縦ラベルになる。Callout、Faq、ProductBox、ProsCons、広告、用語の吹き出しには付けない。論点帯は円弧の角で、縦ラベルは持たない。

縦書きは、背の短いラベルと、広い画面の「条件」「根拠」だけ。本文・章番号・区画見出しは横書き。狭い画面では背を隠し、各区画の左に縦線と横書きの短いラベルを置く。円弧はヒーローの上辺の曲面として残す。

## 12ブロックとシグネチャ枠の対応

| ブロック | 対応する枠 | Spread での形 |
| --- | --- | --- |
| DecisionBrief | S6 に準じる | 右上が円弧の票。対象・範囲はラベルと値。縦ラベルは付けない |
| Summary | S9 | 円弧が閉じる直前。上辺の線だけの要点 |
| Evidence | S6 | 欄外の背「根拠」と点線。本文中の参照番号は文字 |
| Conditions | S6 | 欄外の背「条件」と点線。ラベルと値の基準線をそろえる |
| Callout | — | 主面の中の細い枠。円弧も背も付けない |
| Steps | S4（実務）と同じ目盛り | 手順番号を丸で示す |
| Faq | — | details。円弧も背も付けない |
| ProductBox | — | 主面の中の枠と「サービス」等の文字ラベル。料金・条件は Conditions の背。背や円弧を訴求に使わない |
| CompareTable | S4（比較）と同じ列の罫 | caption、行列見出し、基準日、注記。器の中だけ横にスクロールする |
| ProsCons | — | 2列の票。狭い画面では縦に並べる。円弧も背も付けない |
| Term | S7 | 点線の下線のトリガーと、角の一つが円弧の吹き出し |
| LinkCard | S4 | 記事型の記事面を縮小した形 |

本文は 17px / 16px、行高 1.95、最大幅 40em。記事の h1 は明朝 700 で 34px / 23px。記事の h2 は明朝 22px。章番号は 66px / 46px。

画像の無い論考・人物は、曲面で切った無地の面に話者名を大きく置く。記事ページの確認日は、円弧の内側で明朝を大きくする。
