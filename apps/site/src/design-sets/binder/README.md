# Binder — タブと台紙（標準）

原形は、開く爪と差し込む付箋。左の索引レール、中央の台紙、右の付箋の列で3領域を分ける。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。

| トークン | 値 |
| --- | --- |
| `--g-line` | 1.5px |
| `--g-protrude` | 0.75rem |
| `--g-tab-h` | 1.75rem |
| `--g-tab-shoulder` | 0.625rem |
| `--g-radius` | 0 |
| `--g-step` | 5 |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 開く爪と、台紙へ差し込む付箋 |
| S2 | 棚の位置を示すタブ |
| S3 | ずれる番号タブ（節の仕切り） |
| S4 | タブ付き台紙の変形。実務は手順の目盛り、比較は列の罫、ニュースは日付の爪、論考・人物は重なる題名票 |
| S5 | 引き出し |
| S6 | 横向きタブの票 |
| S7 | 上タブの小台紙 |
| S8 | 開いて台紙と一体化。狭い画面の索引では閉じた枠 |
| S9 | 綴じ線 |

## 形の予約

横向きの付箋（side-tab）は、確かめる領域の部品と、本文の条件欄・根拠欄だけに使う。広告、人気記事、商品の訴求には使わない。

## 12ブロックとシグネチャ枠の対応

| ブロック | 対応する枠 | Binder での形 |
| --- | --- | --- |
| DecisionBrief | S6 に準じる | 上タブ「この記事で分かること」の票。対象・範囲はラベルと値で示す |
| Summary | S9 | 綴じ線の直前に置く要点の票 |
| Evidence | S6 | 左辺タブ「根拠」の票。本文中の参照番号は小さな角形 |
| Conditions | S6 | 左辺タブ「条件」の票。ラベルと値の基準線をそろえる |
| Callout | — | 台紙内の細い枠。タブを付けない |
| Steps | S4（実務）と同じ目盛り | 手順番号を目盛りで示す |
| Faq | — | details。タブを付けない |
| ProductBox | — | 台紙内の枠と「サービス」等の文字ラベル。料金・条件は Conditions と同じ確認票。付箋や確認票の形を商品の訴求に使わない |
| CompareTable | S4（比較）と同じ列の罫 | caption、行列見出し、基準日、注記 |
| ProsCons | — | 2列の票。狭い画面では縦に並べる |
| Term | S7 | 点線の下線のトリガーと、上タブの補足面 |
| LinkCard | S4 | 記事型の記事面を縮小した形 |
