# Answer — 問いと答えの札

原形は、角の丸い「札」。Q・A・◯・△・✕・＝・？の1字を持つ札を、見出し・確かめる情報・現在地に置き、答えが先に見えるようにする。白い帯と丸い札の列（探す）、白い面（読む）、灰の丸い面（確かめる）で3領域を分ける。デザイン案 D（Answer）を移植した。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。

| トークン | 値 |
| --- | --- |
| `--g-line` | 1.5px |
| `--g-radius` | 16px |
| `--g-radius-small` | 10px |
| `--g-pill` | 999px |
| `--g-plate` | 2.5rem |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 白い帯と丸い札の列（探す）、灰の丸い答えの面（確かめる） |
| S2 | 問いの輪（虫めがね）と棚の番号 |
| S3 | 墨の Q の札（Q1・Q2…）と問いの見出し |
| S4 | 問いのカード。題の前に Q の札、要旨は白い答えの面。実務は番号の札、比較は札の列、ニュースは墨の日付の札、論考・人物は角の丸い写真 |
| S5 | 丸い問いの欄と、目的の大きな札 |
| S6 | 灰の丸い面。論点帯は A の札、条件は＝の札と値、根拠は番号の丸 |
| S7 | しっぽで語を指す吹き出し |
| S8 | 今いる棚・節が墨の札になる |
| S9 | ◯の札と墨の帯 |

## 形の予約

- 判定の札（◯ はい・△ 条件つき・✕ いいえ・＝ 値）は、条件と答えの要約、よい点と注意、注記の種類だけに使う。広告・人気の訴求には使わない。
- 点線の札（？）は「未確定」と0件の案内だけに使う。

## 書体

フォントファイルは同梱しない。端末にある書体を指名する。

- `--f-sans`：BIZ UDPゴシック（Windows に標準で入っている UD 書体）、system-ui、Hiragino Sans、Hiragino Kaku Gothic ProN、Yu Gothic UI、Yu Gothic、Meiryo、Noto Sans JP
- `--f-num`（数字）：BIZ UDPゴシック、system-ui、Hiragino Sans、Helvetica Neue、Arial

## 対応する機能

全セット共通の機能（保存・続きから読む・用語の補足・検索・明暗・文字サイズ）にすべて対応する。質感は `flat` と `real`（`finish-real.css`）。
