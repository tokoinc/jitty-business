# Board — 固定盤と差し替えパネル

原形は、太い輪郭の差し替えパネル。左に濃い固定盤を置き、右側を大きさの違うパネルの格子で組む。パネルの大きさが記事型を表す。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。`protrude` のカスタムプロパティ名は `--g-off`。

| トークン | 値 |
| --- | --- |
| `--g-line` | 2px |
| `--g-off` | 0.375rem |
| `--g-radius` | 0.5rem |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 固定盤とパネルの間隔。記事パネルは右下へずらした二重輪郭 |
| S2 | 番号札。棚の番号を大きく、棚名と記事型を小さく |
| S3 | 行帯。記事の h2 は行帯と、左の節番号の札 |
| S4 | 記事型でパネル寸法。解説 2×1、実務 2×1＋目盛り、比較 2×2＋ミニ表、ニュース 1×1＋日付の帯、論考・人物 1×2 |
| S5 | 操作盤。条件は正方形のキー。選ぶと二重線が重なって押し込まれた形になる |
| S6 | 計器パネル。同心の二重輪郭と、見出しの横の目盛り |
| S7 | ずらした二重輪郭の小パネル（`.bo-pop` だけ。記事面のクラスは付けない） |
| S8 | 押し込み。固定盤の棚スイッチ、目次の現在の節、索引の目的・用語集・保存 |
| S9 | 全幅の終端。太い上辺と「ここまで」 |

## 形の予約

| 形 | 使ってよい部品 |
| --- | --- |
| ずらした二重輪郭 | 記事面（face）、記事パネル（article） |
| 同心の二重輪郭 | 論点帯、条件、根拠、目次、選択中の条件、読みかけ、連載、最近確認した記事 |

Callout、Faq、ProductBox、ProsCons、広告には、どちらの輪郭も付けない。S7 の小パネルは工程16の部品表に従い `.bo-pop` だけがずらした輪郭を持つ。計器や商品の訴求には使わない。

## 12ブロックとシグネチャ枠の対応

| ブロック | 対応する枠 | Board での形 |
| --- | --- | --- |
| DecisionBrief | S6 に準じる | 同心の計器。題は行帯。対象・範囲はラベルと値 |
| Summary | S9 | 終端の直前。太い上辺は EndMark に任せ、要点はずらした輪郭にしない |
| Evidence | S6 | 同心の計器。本文中の参照番号は文字 |
| Conditions | S6 | 同心の計器。ラベルと値の基準線をそろえる |
| Callout | — | パネル内の細い枠。二重輪郭を付けない |
| Steps | S4（実務）と同じ目盛り | 手順番号を、区切った一本の帯で示す |
| Faq | — | details。帯や二重輪郭を付けない |
| ProductBox | — | パネル内の枠と「サービス」等の文字ラベル。料金・条件は Conditions の計器。輪郭を訴求に使わない |
| CompareTable | S4（比較）と同じ列の罫 | caption、行列見出し、基準日、注記。器の中だけ横にスクロールする |
| ProsCons | — | 2列の票。狭い画面では縦に並べる。二重輪郭を付けない |
| Term | S7 | 点線の下線のトリガーと、ずらした小パネル |
| LinkCard | S4 | 記事型の記事面を縮小した形（compact は 1×1） |
