# Tally — マス目で数える

原形は、1マス＝1つのマス目。数・進み具合・現在地を、埋めたマスの数と位置で示す。上の濃い帯（探す）、白い面（読む）、角にマスを持つ箱の列（確かめる）で3領域を分ける。デザイン案 C（Tally）を移植した。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。

| トークン | 値 |
| --- | --- |
| `--g-line` | 2px |
| `--g-line-thin` | 1.5px |
| `--g-cell` | 12px |
| `--g-cell-gap` | 3px |
| `--g-corner` | 16px |
| `--g-radius` | 0 |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 濃い緑の帯（探す）と、左上の角にマスを持つ箱（確かめる） |
| S2 | 2×2のマス。棚の番号の数だけ埋める |
| S3 | 節の数だけマスを並べ、読み進めた節まで埋める（「03 / 06」） |
| S4 | 角のマスを持つ面。実務は番号付きの濃いマス、比較はマスの行列、ニュースは日付の濃いマス、論考・人物は大きな1マスの写真 |
| S5 | 目的をマスのキーで選ぶ。条件群はマスのチェック |
| S6 | 角にマスを持つ箱。条件は1行が1マス、根拠は番号のマス |
| S7 | ずらした影を持つ箱。左上にマス |
| S8 | 今いる棚・節のマスが埋まる（帯の上では明るい緑の面） |
| S9 | 6つすべて埋まったマスの列と「ここまで」 |

## 形の予約

- 埋めたマスは「数えたもの」（手順・節・件数）と現在地、棚の印だけに使う。飾りの点や広告には使わない。
- 点線のマスは「未確定」（未発表・採択のあと など）だけに使う。

## 書体

フォントファイルは同梱しない。端末にある書体を指名する。

- `--f-sans`：system-ui、Hiragino Sans、Hiragino Kaku Gothic ProN、Yu Gothic UI、Yu Gothic、Meiryo、Noto Sans JP
- `--f-num`（数字）：Bahnschrift（Windows）、DIN Alternate（macOS・iOS）、Roboto（Android）、Helvetica Neue、Arial。無いときは `--f-sans`

## 対応する機能

全セット共通の機能（保存・続きから読む・用語の補足・検索・明暗・文字サイズ）にすべて対応する。質感は `flat` と `real`（`finish-real.css`）。
