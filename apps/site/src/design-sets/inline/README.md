# Inline — 文中の小さな図

原形は、字の高さに収まる短い棒・目盛り・細い線。数と進み具合を文字のすぐ横に置く。面は白と淡い灰、線は細く、色は藍1色で、れんが色は今日と注意だけに使う。ほかのセットより控えめ。白い帯と細い線（探す）、白い面（読む）、淡い灰の面（確かめる）で3領域を分ける。デザイン案 F（Inline）を移植した。

## 幾何トークン

`tokens.css` の `--g-*` は `manifest.geometry` と一致する。

| トークン | 値 |
| --- | --- |
| `--g-line` | 1px |
| `--g-bar` | 5px |
| `--g-hair` | 2px |
| `--g-radius` | 14px |
| `--g-radius-small` | 8px |

## 9枠

| 枠 | 形 |
| --- | --- |
| S1 | 白い帯と細い線（探す）、淡い灰の角の丸い面（確かめる） |
| S2 | 短い棒の列。棚の位置の棒だけ藍 |
| S3 | 見出しと、記事の中の進み具合を長さで示す細い線（「3 / 6」） |
| S4 | 白いカードの下端に記事型ごとの小さな図。実務は手順の数の短い棒、比較は短い縦の棒、ニュースは目盛りと日付、論考・人物は角の丸い写真 |
| S5 | 淡い検索欄と、目的の小さな札 |
| S6 | 淡い面（論点帯）と白いカード（条件欄・根拠欄）。根拠は番号の丸 |
| S7 | 上端に藍の細い帯を持つ白いカード |
| S8 | 今いる棚・節の下に藍の線。目次は読んだ節の棒が満ちる |
| S9 | 満ちた1本の棒と「ここまで」 |

## 形の予約

- 小さな図（短い棒・目盛り）は数と進み具合と範囲だけに使う。飾りには使わない。
- れんが色は「今日」と注意だけに使う。

## 12ブロックとシグネチャ枠の対応

| Faq | — | Q と開閉の印 |
| ProductBox | — | 細い線の角の丸い枠。料金・条件は Conditions と同じ票 |

| ProsCons | — | 藍の点（よい点）とれんが色の輪（注意） |
| Term | S7 | 点線の下線と ? の丸。補足は上端に藍の帯を持つカード |
| LinkCard | S4 | 記事面を小さくした形 |

## 書体

フォントファイルは同梱しない。端末にある書体を指名する。

- `--f-sans`：system-ui、Hiragino Sans、Hiragino Kaku Gothic ProN、Yu Gothic UI、Yu Gothic、Meiryo、Noto Sans JP
- `--f-num`（数字）：system-ui、Segoe UI、Helvetica Neue、Arial。無いときは `--f-sans`

## 対応する機能

全セット共通の機能（保存・続きから読む・用語の補足・検索・明暗・文字サイズ）にすべて対応する。質感は `flat` と `real`（`finish-real.css`）。

## 識別検査

人による識別検査（A〜F）はまだ行っていない（`docs/identity/2026-10-08-impl.md`）。
