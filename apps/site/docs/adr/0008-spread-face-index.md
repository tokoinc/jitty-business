# Spread の記事面の番号は、一覧の位置を JS が埋める

## 状況

Spread の解説・実務の記事面は、一覧の中の順番を大きな番号にする（2.8、2.10）。`ArticleFace` の `index` は任意。ホーム・一覧・用語・連載は、すでに並びの 1 から渡している。検索結果と保存一覧は、`face-{format}` の `<template>` を複製して描く。テンプレートを書いた時点では、何番目になるか決まらない。

## 選択肢

1. テンプレートに仮の番号を書き、JS では変えない。
2. 解説・実務の面に空の `[data-field="index"]` を置き、描くときに 1 から埋める。サーバで描く面は、呼び出し側が `index` を渡す。

## 決定

選択肢2。番号は `01` の形で、見出しの外に `aria-hidden` で置く。比較・ニュース・論考・人物には番号を出さない。

- 次に確かめる: 主の候補から回り道まで、並びの 1 から渡す。
- 本文中のリンクカード: 1枚なので `1`。
- 検索結果: いま表示している結果の順（最大30件）の 1 から。
- 保存一覧: 保存日時の新しい順の 1 から。

`index` を渡さないテンプレートは、番号の要素を空のまま出す。JS がその文字を埋める。

## 理由

番号は装飾であり、見出しの文字やリンク先には入れない。テンプレートは記事型ごとに1つなので、位置は複製したあとでしか決まらない。
