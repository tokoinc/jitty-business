## 合格基準（2.16）

判定者は5名以上、うち制作者以外を3名以上。集めにくい場合も、制作者以外の最低3名で行い、人数を記録する。

| 検査 | 合格基準 |
| --- | --- |
| A 同一性 | 判定者の80%以上が、対象の4画面をすべて同じ組にまとめる |
| B 部品 | 6部品中5部品以上で、判定者の過半数が正しいセットを選ぶ |
| C セット間 | 全判定者が区別でき、違いを位置・境界・張り出しなどの形の言葉で説明できる |
| D 縮小 | 判定者の80%以上がセットを当てる |
| E 狭い画面 | 検査Aと同じ |
| F 作業 | 各作業の成功率90%以上。形が原因のつまずきは修正して再検査する |

色・書体・角丸の値の調整では合格にしない。不合格のときは、そのセットの `parts.css`（形）を直す。
