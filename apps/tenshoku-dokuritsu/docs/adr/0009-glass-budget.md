# すりガラスは、見える面で6枚までにする

## 状況

2.13 は、未選択の棚スタンプと問いの円と背をすりガラスにする。同時に、1画面のすりガラスは6面までである。実装の Spread は、棚スタンプがホームと棚3つ、問いの円が索引に3つ、検索面にもう3つ、背が1つある。見本どおり全部に `backdrop-filter` を付けると、広い画面のホームは7面、検索は9面になる。選択中のスタンプは見本でも不透明な球である。

## 選択肢

1. 見本どおり、未選択のスタンプ・索引の問い・検索の問い・背のすべてをすりガラスにする。6面の上限は超える。
2. 上限を守るため、索引の問いの円は不透明な面にする。すりガラスは、未選択の棚スタンプ、背、検索面の問いの円だけにする。狭い画面で索引を開いたときは、上のタブ列のぼかしを外し、開いた索引のスタンプと二重に数えない。
3. スタンプを不透明にし、問いの円をすりガラスにする。棚のスタンプが、Spread の主な質感でなくなる。

## 決定

選択肢2。Board のすりガラスは、計器（`.bo-meter`）と検索欄（`.bo-query__field`）だけにする。本文の面（Board のパネルと記事面、Spread の主面と次の見開き）には付けない。検索画面では棚が現在地にならないため、未選択のスタンプが4つになる。そこではスタンプを不透明にし、すりガラスは検索面の問いの円3つにする。数えるときは、`checkVisibility()` が真で、`backdrop-filter` が `none` でない要素だけを1面とする。

## 理由

6面は工程18の完了条件である。索引の問いと検索面の問いは同じ3つの問いなので、すりガラスは検索面（S5）に置く。未選択のスタンプと背は、2.13 の Spread の主な部品として残す。広い画面では、ホーム・一覧・記事が未選択のスタンプと背で6面以内、検索は問いの円3面になる。
